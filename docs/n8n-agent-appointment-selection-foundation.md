# Fundação da seleção de agendamento

Esta fundação reconhece uma escolha explícita entre até cinco agendamentos previamente obtidos de fonte confiável.

São aceitos ordinais de primeiro a quinto, “último” e data local explícita, opcionalmente acompanhada de horário. Datas ambíguas, mais de um seletor, ordinal inexistente, estado não elegível, identidade duplicada ou data inválida falham de forma fechada.

O módulo é puro: não consulta banco, não envia mensagens e não cria, cancela ou remarca agendamentos. A integração com contexto conversacional e propostas ocorrerá em etapas posteriores.
