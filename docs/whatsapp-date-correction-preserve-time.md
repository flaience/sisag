# Correção conjunta de data e horário no WhatsApp

Quando existe uma proposta pendente e o cliente informa uma nova data junto com um novo horário, ambos os valores devem substituir a proposta anterior no mesmo turno.

Exemplo: `Quero agendar amanhã às dez horas` não deve provocar uma nova pergunta sobre o horário. O assistente consulta imediatamente a disponibilidade da nova data às 10:00 e apresenta a confirmação ou alternativas reais.

Se a correção trouxer somente a data, o assistente continua perguntando qual horário o cliente prefere. Nenhuma reserva é criada sem uma confirmação posterior e explícita.
