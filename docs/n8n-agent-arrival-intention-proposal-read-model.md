# Read model da proposta de intenção de comparecimento

O read model resolve uma escolha do cliente exclusivamente contra até cinco períodos ativos carregados para a empresa, data, unidade e serviço confiáveis. A capacidade considera somente intenções registradas na data concreta.

O identificador do período vem do banco e nunca do texto do cliente. Uma escolha ambígua ou indisponível retorna `not_resolved`. O incremento não está ligado ao gateway, não envia mensagens, não registra intenção e não executa check-in.
