# Resposta candidata dos próximos agendamentos

O formatador determinístico produz uma lista localizada de no máximo cinco compromissos pendentes ou confirmados. A saída contém somente data, hora, serviços e estado, com texto limitado a 500 caracteres.

Resultados vazios e falhas possuem mensagens próprias e não inventam compromissos. Esta etapa amplia o contrato de resposta sombra, mas ainda não integra o workflow nem autoriza envio ao WhatsApp.
