# Roteador compartilhado no webhook de texto

O webhook delega a interpretação do resultado da decisão ao roteador compartilhado. A precedência de handoff, cancelamento, remarcação, proposta de novo agendamento e resposta candidata permanece inalterada.

Confirmações de comandos continuam antes da decisão. O fallback atual continua depois do roteamento. Áudio ainda não é ativado nesta etapa.
