# Workflow sombra v15 — ordem de chegada

A v15 preserva o fluxo sombra da v14 e adiciona a resposta candidata para `scheduling.list_arrival_periods`.

- O workflow permanece inativo e sem retenção de execuções.
- A resposta contém apenas data, serviço, unidade, período e capacidade restante.
- O texto é limitado a 500 caracteres e cinco períodos.
- Não há envio, registro de intenção, cancelamento, check-in ou posição em fila.
