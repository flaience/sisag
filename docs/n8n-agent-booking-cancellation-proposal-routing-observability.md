# Observabilidade do roteamento da proposta de cancelamento

Falhas de elegibilidade e persistência passam a registrar somente correlação, etapa e código técnico limitado. Telefone, mensagem, serviço e dados do agendamento não são observados.

Quando a proposta explícita não puder ser persistida, uma resposta neutra informa que nada foi alterado. O candidato de status não pode mais substituir silenciosamente a pergunta de cancelamento.
