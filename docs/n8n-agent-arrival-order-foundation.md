# Fundação do agente para ordem de chegada

Esta etapa reconhece somente pedidos explícitos de atendimento por ordem de chegada com uma data concreta e prepara uma resposta sanitizada a partir de períodos confiáveis.

- Não confunde horário marcado, cancelamento ou remarcação.
- Não registra intenção automaticamente.
- Não reserva horário ou posição em fila.
- Não está conectada ao fluxo de produção nesta etapa.
