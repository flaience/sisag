# Fundação da proposta de remarcação do agente n8n

Esta etapa cria somente uma proposta efêmera de remarcação. Ela exige intenção explícita, um agendamento futuro ativo pertencente ao contexto confiável e exatamente um novo horário oferecido para o mesmo serviço.

A proposta compara o horário atual com o novo horário e solicita **SIM** ou **NÃO**. O envio e a execução permanecem bloqueados. Nenhum agendamento é alterado nesta etapa.
