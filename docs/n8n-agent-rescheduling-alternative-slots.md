# Alternativas para horário de remarcação indisponível

A preparação da remarcação consulta primeiro a partir do horário solicitado. Quando não há nenhum slot posterior no mesmo dia, faz uma segunda consulta somente leitura a partir do início daquele mesmo dia local.

As alternativas permanecem limitadas a vinte slots, ao mesmo serviço e ao mesmo período. Se existirem, o candidato seguro de disponibilidade apresenta opções ao cliente; nenhuma remarcação ocorre sem nova escolha e confirmação explícita.
