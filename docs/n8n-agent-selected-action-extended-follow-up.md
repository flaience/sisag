# Continuação estendida da ação selecionada

Uma ação somente leitura resolvida, como `Remarque o primeiro`, pode ser continuada com a nova data e hora por até uma hora.

A janela estendida vale exclusivamente para `scheduling.resolve_selected_appointment_action` concluída com sucesso. Os demais contextos permanecem limitados a quinze minutos. A busca continua restrita por empresa, conta do WhatsApp, remetente e mensagem recebida.
