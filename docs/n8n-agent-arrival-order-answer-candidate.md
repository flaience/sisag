# Resposta candidata para ordem de chegada

O resultado confiável do gateway é convertido em uma resposta candidata com data, serviço, unidade, período e capacidade restante.

- Texto e quantidade de períodos são limitados pelo contrato sombra.
- Identificadores internos não são expostos.
- Nenhum horário ou posição em fila é prometido.
- A resposta ainda não é roteada para produção e nenhuma intenção é registrada.
