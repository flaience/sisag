# Entrada única do agente n8n

Texto do WhatsApp, transcrição de áudio e homologação passam a compartilhar o mesmo formato de entrada antes de chegar à decisão sombra.

Esta fundação não muda regras, não consulta banco, não envia mensagens e não executa agendamentos. Ela evita que cada canal recrie decisões, confirmações e contratos já validados.

## Próximas integrações

1. encaminhar o texto recebido para a entrada comum;
2. encaminhar a transcrição de áudio para a mesma entrada;
3. manter a homologação como suíte principal de regressão;
4. testar no áudio apenas transcrição, normalização e integração com a entrada comum.
