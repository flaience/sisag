# Continuidade de data e horário para novo agendamento

Uma data isolada deixa de ser interpretada automaticamente como seleção de agendamento existente.

- após pedido de novo horário, a data continua no fluxo de agendamento;
- após lista confiável de próximos agendamentos, a data pode selecionar um compromisso;
- sem contexto, a decisão permanece fechada.
