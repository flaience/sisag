# Escolha contextual de horário disponível

Quando o agente acabou de listar horários disponíveis, uma resposta ordinal ou um horário explícito permanece no fluxo de disponibilidade. O contexto usa o marcador reconhecido pelo workflow v14 e o contrato de decisão proíbe interpretar essa resposta como seleção de um agendamento existente.

A mudança não executa reserva. A proposta de confirmação continua com execução bloqueada.
