# Read model do agente para ordem de chegada

O read model consulta períodos ativos da empresa para uma data concreta, conta intenções registradas e devolve no máximo cinco opções ainda disponíveis.

- Somente serviços configurados para ordem de chegada são considerados.
- Unidade, serviço, período e intenções são sempre filtrados pela empresa autenticada.
- Filtros de manhã, tarde, noite e serviço são aplicados sobre dados confiáveis.
- Nenhum registro ou alteração é realizado.
