# SPEC-005

# Operational Context Specification

Status

Stable

Versão

1.0

---

# Definição

O Operational Context representa a fonte única da verdade operacional.

---

# Princípios

- unicidade;
- consistência;
- rastreabilidade;
- independência tecnológica.

---

# O Contexto nunca pertence a um produto.

Produtos apenas o representam.

---

# Toda decisão operacional deve ser explicável através do Contexto.
