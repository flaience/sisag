# SPEC-004

# Operational Event Specification

Status

Stable

Versão

1.0

---

# Definição

Um Operational Event representa uma mudança observável da realidade operacional.

---

# Todo evento deve possuir

- nome;
- contexto;
- timestamp;
- origem;
- payload;
- correlação.

---

# Eventos são imutáveis.

Nunca podem ser alterados após sua emissão.

---

# Eventos representam fatos.

Nunca intenções.
