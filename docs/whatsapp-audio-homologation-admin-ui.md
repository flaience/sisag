# Áudio na tela de homologação do WhatsApp

A tela permite selecionar uma amostra nos formatos aceitos pela produção. A API autenticada transcreve o arquivo e preenche o campo de mensagem.

O operador revisa e pode corrigir o texto antes de executar a homologação. A transcrição não dispara automaticamente o agente, não envia WhatsApp e não executa propostas.
