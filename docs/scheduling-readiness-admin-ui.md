# Verificação administrativa da agenda

A tela **Configurações → Verificação da agenda** permite escolher local, serviço e profissional e consultar o checklist somente leitura da prontidão.

O resultado identifica cada requisito válido ou pendente, mostra alertas de bloqueios ativos e oferece atalhos para a tela responsável pela correção. A interface consome apenas a API administrativa de prontidão e não cria, altera ou remove configurações.
