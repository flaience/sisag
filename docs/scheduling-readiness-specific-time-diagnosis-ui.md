# Diagnóstico específico na tela de prontidão

A consulta de data e horário da tela de prontidão usa a API administrativa de diagnóstico. O resultado diferencia jornada ausente, distribuição não coberta, direcionamento para outro profissional e indisponibilidade depois de jornada e distribuição válidas.

Cada situação apresenta explicação, atalho corretivo e alternativas ordenadas pela proximidade do horário solicitado. A interação permanece somente leitura.
