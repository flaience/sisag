# Tela administrativa de períodos por ordem de chegada

A tela em `/admin/settings/arrival-periods` permite configurar unidade, serviço, dia, início, fim e capacidade opcional. Somente serviços ativos configurados para ordem de chegada são apresentados.

A capacidade limita futuros registros antecipados e não representa posição na fila. A tela não cria check-in, atendimento ou fila.
